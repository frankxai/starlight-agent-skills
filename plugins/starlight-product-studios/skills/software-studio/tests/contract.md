# Contract test — software-studio

The output must prove:

- [ ] Scope, non-goals, interfaces, data/state ownership and accepted architecture decisions are explicit.
- [ ] Threat, permission, secrets, dependency, migration, failure, retry and rollback paths are reviewed.
- [ ] Required format, type, test, accessibility, performance and compatibility gates pass on the exact revision.
- [ ] Preview, production deployment and public availability are never conflated.
- [ ] Telemetry attributes outcome, latency, errors and model/runtime cost to the product.
- [ ] Merge, production, submission, pricing, spending and external communication respect authorization.
