# Example — Customer interview synthesis

## Input

A startup founder wants a reusable skill that turns interview notes into a decision brief and a learning exercise, for Codex and Claude.

## Output

```json
{
  "outcome": "A decision brief that distinguishes interview evidence from assumptions, with an exercise to check a claim against excerpts.",
  "artifact": "Draft contract for customer-interview-synthesis; package export remains to be compiled.",
  "evidence": ["The requested audience, outcome, and two target hosts are specified."],
  "next_steps": ["Compile the draft without private interview content.", "Run a representative and a misleading-source scenario in each intended host; record actual results."]
}
```

The example is a proposed handoff; it does not assert that a package or host test exists.
