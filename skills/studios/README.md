# Specialist studio skills

These five portable vertical managers execute the federated product-studio contract governed by `frankxai/agentic-ops`.

- `publishing-studio`
- `template-studio`
- `software-studio`
- `media-studio`
- `world-experience-studio`

Every product has one primary studio. Other studios may receive bounded sub-envelopes, but the primary manager retains product identity, shared-state and release synthesis. Product repositories remain canonical source; studio skills coordinate work and evidence.
