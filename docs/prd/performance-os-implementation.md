# Performance OS — engineering work packages

## A — Foundation
Canonical JSON schema, aliases, deterministic metric library, parser fixtures and CI. Include unilateral, bodyweight, equipment stack, RPE, null, correction, timezone and duplicate cases. Never infer completed sets from a summary note.

## B — Google Workspace adapter
OAuth scope inventory, Sheets read-only importer, user-approved writer, revision-based reconciliation, receipt logs, data export and revocation test. Detect existing workbook rows that encode multiple sets in one row; mark historical metrics provisional.

## C — Portable Agent Skill
`SKILL.md` with trigger boundaries, exact tools, privacy policy, confirmations and fail-closed behavior. Add OpenCode/Claude/Codex/Gemini examples without provider lock-in.

## D — Coach pilot
Approval inbox, weekly evidence-backed drafts, tenant isolation, role-based permissions, report correctness evals, and pilot instrumentation.

## E — Optional UI
Local-first PWA and muscle exposure visualization only after A–D are validated. Heatmaps must label model-derived exposure, not measured activation.

## Definition of done
Every work package has runnable tests, security review, measured cost, evidence receipts, documentation and independent reviewer. No fabricated live status, performance benchmark or scientific assertion.
