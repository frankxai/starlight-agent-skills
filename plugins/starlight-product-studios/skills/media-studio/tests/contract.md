# Contract test — media-studio

The output must prove:

- [ ] Creative premise, audience effect, reference boundary and exclusions are explicit.
- [ ] Rights, consent, samples, splits, licenses, models/tools and attribution are recorded before release.
- [ ] Editable masters, approved renditions, previews and channel metadata share stable asset/work IDs and versions.
- [ ] Taste, continuity, similarity, technical and accessibility checks have independent evidence.
- [ ] External generation spend stays within the envelope and is reported.
- [ ] Publication, licensing grants and minting remain human-authorized.
