# Starlight Second Brain

Six portable workflows for source-backed knowledge, with a deterministic offline explorer.

This is the working-knowledge interface over existing sources, not a second memory database. Starlight Memory remains the infrastructure adapter; the source owner retains authority. No MCP endpoint, hosted application, auto-capture, provider subscription or schedule is installed.

Start with “Resume this project from its latest source-backed context.” Use “Map my knowledge sources and trace the decisions that matter” for an inventory. For a visual, supply a selected packet and invoke Explore Knowledge. The explorer has graph, list, timeline and source views, filters, evidence details and export.

Source: `skills/substrate/` in the existing Starlight Agent Skills repository. Run `python3 scripts/build_second_brain_plugin.py --check` to check compiled projection drift.

The included packet is synthetic. Keep personal data outside this package and outside public source history.

Built on SIP.
